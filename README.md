# 병원 스케줄 분석 에이전트 (Mr Schedule Agent)

병원 외래 스케줄 사진을 업로드하면 Claude AI가 모든 의사의 진료 일정을 자동으로 추출합니다. MR(Medical Representative) 업무 지원 전용 도구입니다.

🌐 **배포 주소**: https://karmawolf-git.github.io/HTimeTable/

## 주요 기능

- 📸 **다중 이미지 업로드** — 여러 장 동시 선택, 드래그 앤 드롭 지원
- 🤖 **2단계 AI 분석** — 진료과 목록 파악 → 진료과별 의사 순차 추출
- 📋 **목록 보기** — 의사명 / 진료과 / 외래 일정 / 진료실 / 비고
- 📅 **요일별 보기** — 월~토 × 오전/오후 그리드로 한눈에 확인
- 🔍 **필터링** — 이름 검색, 진료과별, 요일별 필터
- 📤 **클립보드 복사** — 엑셀에 바로 붙여넣기 가능한 TSV 형식

## 시작하기

### 1. 의존성 설치

```bash
npm install
```

### 2. 개발 서버 실행

```bash
npm run dev
```

### 3. API 키 설정

브라우저에서 앱을 열면 Anthropic API 키 입력창이 나타납니다.  
[Anthropic Console](https://console.anthropic.com/)에서 발급한 `sk-ant-api...` 키를 입력하세요.  
키는 브라우저 `localStorage`에만 저장되며 외부로 전송되지 않습니다.

### 4. 빌드

```bash
npm run build
```

## 사용 방법

1. 병원 외래 스케줄 게시판 사진을 준비합니다 (JPG / PNG / WEBP)
2. 이미지를 업로드합니다 (여러 장 동시 가능)
3. **전체 분석 시작** 버튼을 클릭합니다
4. 분석 완료 후 **목록** 또는 **요일별** 탭에서 일정을 확인합니다
5. **복사** 버튼으로 전체 데이터를 엑셀에 붙여넣기 합니다

## 기술 스택

- **React 18** + **Vite 5**
- **Claude claude-sonnet-4-20250514** (Vision API)
- 스타일: 인라인 CSS (외부 의존성 없음)
- 배포: GitHub Pages (GitHub Actions)

## 분석 방식

1단계에서 진료과 목록을 파악하고, 2단계에서 진료과별로 순차 분석하여  
스케줄 표가 복잡하더라도 모든 의사 정보를 빠짐없이 추출합니다.
